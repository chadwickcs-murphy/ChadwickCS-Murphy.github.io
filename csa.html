AP Computer Science A (25-26)

Course Description

This course is designed for 10th-12th-grade students with some background in programming. Students interested in taking the course should reach out to the teacher to determine if their prior background is sufficient. In this course, students learn to use the Java programming language and the object-oriented programming paradigm to design and construct solutions to problems. Along the way, students are introduced to fundamental algorithms and data structures used to organize and process data. Audited and approved by the College Board, this course also prepares students for the AP Computer Science A exam in May.

Grading and Assessments

This course will use a range of assessments. These include written assessments, online assessments, and labs that all are designed to measure understanding and a student’s ability to apply their knowledge.

Learning Goals
  • Conceptual Understanding (40%)
    • Ability to demonstrate knowledge of course concepts
    • Ability to trace Java code

  • Technical Application (60%)
    • Ability to problem solve
    • Ability to write Java code
