Introduction to Coding (25-26)

Course Description

This course is designed for students that have minimal programming experience but are looking for a chance to learn more about programming. Students will mainly create graphical applications while they learn the basics of Java. This course is also designed to prepare students for AP Computer Science A.

Week 5 - Incorporating the Mouse
  • mouseX, mouseY
  • mouseWheel(MouseEvent event)
    {
       float e = event.getCount();
       code block that runs when the mouse wheel is moved
    }
  • mousePressed()
    {
       code block that runs when the mouse button is pressed
    }
Week 4 - Bouncing Shapes
  • width, height
  • setup()
    {
       code block that runs when the program starts
    }
  • draw()
    {
       code block that runs over and over after setup() runs;
       the screen refreshes after this executes
    }
  • if (test)
    {
       code block that runs if test is true
    }
  • if (test)
    {
       code block that runs if test is true
    }
    else
    {
       code block that runs if test is false
    }
Week 3 - Transformations
  • PI
  • translate(xShift, yShift)
  • rotate(angle-in-radians) - 360 degrees = 2 * PI radians; 45 degrees = PI / 4 radians
Week 2 - Repeating Shapes
  • for (start; end test; increment)
    {
       code block that gets repeated
    }

    Examples:
    • for (int i = 1; i <= 10; i = i + 1)
    • for (int i = 10; i >= 1; i = i - 1)
    • for (int i = 1; i <= 100; i = i + 10)
